# AMICS Website Design System

Adapted from the supplied Hyring DESIGN.md while preserving AMICS' white-major/red-accent identity.

## Colors
- Primary: `#d71920` — AMICS red
- Primary dark: `#b9141a`
- Background: `#ffffff`
- Soft background: `#f5f5f3`
- Dark surface: `#151515`
- Text: `#111111`
- Muted text: `#686868`
- Border: `#dddddd`

## Typography
- Family: Inter
- H1: 600 weight, responsive 48–72px, tight tracking
- H2: 600 weight, responsive 38–58px
- H3: 600 weight, 20–22px
- Body: 400 weight

## Shape & spacing
- Standard radius: 8px
- Pills: 9999px
- Main spacing rhythm: 10 / 12 / 16 / 20 / 30 / 32px
- Section spacing expands the source system for a modern B2B marketing layout.

## Components
- Primary buttons: red background, white text, 8px radius, 14–20px padding
- Cards: white background, 1px neutral border, 8px radius, restrained hover shadow
- Links: near-black by default; red for technical calls to action
- Dark sections: near-black background with white headings and muted secondary copy

## Visual direction
Clean industrial engineering aesthetic: white space, technical labels, numbered sections, restrained motion, schematic-style hero artwork, and red used deliberately rather than as a large background color except for the final CTA.
