# AMICS design system

Adapted from the uploaded Hyring design guide. All green brand tokens have been replaced with AMICS red.

- Primary: #b40e08; hover #8d0b06
- Background: #ffffff; alternate section #f7f8f9; accent tint #fff4f3
- Text: #202124; supporting text #61666d
- Typeface: Inter, locally hosted, weights 400/600/700
- Headline: responsive up to 68px; medium and semibold weights
- Cards and buttons: 8px corners; restrained borders and light shadows
- Content width: 1240px; desktop page gutter 40px; phone gutter 20px
- Responsive grids: three/two/one columns, depending on content and viewport
- Contact: email/call/WhatsApp, persistent compact mobile actions
- Accessibility: visible focus, skip link, native dialog, reduced motion, keyboard navigation
- Assets: original AMICS logo, hero illustration and real project photography; consistent illustrative product/solution imagery
